Recomanat
Prompt 1 · Panel multi-joc
6 mini-jocs en un · Quiz · Memory · Ordena · Wordle · Exit ticket · Repte final
Consells
  • El format més complet: els alumnes hi poden tornar per repassar.
  • En mode Pas a pas els mini-jocs mostren menys preguntes i el Wordle dona més pistes.
  • Itera al xat sense tornar a generar: "Corregeix la pregunta 4", "Afegeix so d'encert".
Activitat
Prompt 2 · Quiz / concurs televisió
1 joc ràpid · 4 opcions · temporizador · marcador · confeti
Consells
  • Ideal per repassar nomenclatura, definicions o procediments curts.
  • Demana almenys un 60% de preguntes bàsiques i un 40% de nivell mitjà.
  • Especifica que el feedback mostri el procediment, no sols la resposta.
Activitat
Prompt 3 · Escape room
Reptes encadenats · codi final · feedback verd/vermell
Consells
  • Perfecta per tancar un tema: requereix dominar els conceptes per avançar.
  • En mode Pas a pas, cada repte mostra els passos amb buits a omplir.
Activitat
Prompt 4 · Simulador / calculadora interactiva
Explorar relacions · visualització en temps real · descoberta guiada
Consells
  • Ideal per introduir un concepte nou: l'alumne experimenta i descobreix la regla.
  • Afegeix sempre preguntes guiades ("Descobreix") perquè quedin registrades a la taula.
Activitat
Prompt 5 · Memory + Ordena / Classifica
2 mini-jocs en un · parelles · arrossegar i deixar anar
Consells
  • El Memory va molt bé per a fraccions↔decimals↔percentatges.
  • L'Ordena serveix per ordenar fraccions, classificar nombres, o ordenar passos d'un procediment.
